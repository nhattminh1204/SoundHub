# SOUNDHUB - TECHNICAL DOCUMENTATION

## 📋 **TỔNG QUAN DỰ ÁN**

**Tên dự án:** SoundHub - Website bán thiết bị âm thanh  
**Công nghệ:** Java Servlet + JSP + MySQL + Bootstrap 5  
**Kiến trúc:** MVC Pattern + DAO Pattern  
**Database:** MySQL với 6 tables chính

## 🗄️ **CẤU TRÚC DATABASE**

### **1. users**
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    phone VARCHAR(15),
    password VARCHAR(255) NOT NULL,  -- BCrypt hashed
    role VARCHAR(20) DEFAULT 'user'  -- 'user' hoặc 'admin'
);
```

### **2. categories**
```sql
CREATE TABLE categories (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL
);
-- Data: 1='Tai nghe Bluetooth', 2='Tai nghe có dây', 3='Loa Bluetooth'
```

### **3. products**
```sql
CREATE TABLE products (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    image VARCHAR(255),
    category_id INT,
    status TINYINT DEFAULT 1,  -- 1=active, 0=inactive
    quantity INT DEFAULT 0,
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

### **4. cart_items**
```sql
CREATE TABLE cart_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    product_id INT NOT NULL,
    quantity INT DEFAULT 1,
    added_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    UNIQUE KEY unique_cart (user_id, product_id)
);
```

### **5. orders**
```sql
CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT,
    total_amount DECIMAL(10,2),
    shipping_fee DECIMAL(10,2),
    payment_method VARCHAR(50),  -- 'COD' hoặc 'Chuyển khoản'
    status VARCHAR(20) DEFAULT 'pending',  -- pending/confirmed/shipping/delivered/cancelled
    shipping_address TEXT,
    phone VARCHAR(15),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

### **6. order_items**
```sql
CREATE TABLE order_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    order_id INT,
    product_id INT,
    quantity INT,
    price DECIMAL(10,2),  -- Giá tại thời điểm đặt hàng
    FOREIGN KEY (order_id) REFERENCES orders(id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
);
```

## 👤 **CHỨC NĂNG USER**

### **1. AUTHENTICATION**

#### **Đăng ký (Register)**
**URL:** `/register`  
**Method:** GET (hiển thị form), POST (xử lý đăng ký)  
**Servlet:** `RegisterServlet`

**Flow chi tiết:**
```
1. GET /register → RegisterServlet.doGet()
   → Forward tới views/register.jsp
   → Hiển thị form đăng ký

2. User điền form → POST /register
   → RegisterServlet.doPost()
   → Validation: email format, phone format, password strength
   → Check email đã tồn tại: UserDAO.findByEmail()
   → Hash password: BCrypt.hashpw()
   → Insert user: UserDAO.insert()
   → Redirect tới login với success message
```

**Code key:**
```java
// RegisterServlet.doPost()
String hashedPassword = BCrypt.hashpw(password, BCrypt.gensalt());
boolean success = Database.getUserDAO().insert(name, email, phone, hashedPassword, "user");
```

#### **Đăng nhập (Login)**
**URL:** `/login`  
**Method:** GET, POST  
**Servlet:** `LoginServlet`

**Flow chi tiết:**
```
1. POST /login với email + password
   → LoginServlet.doPost()
   → UserDAO.login(email, password)
   → SQL: SELECT * FROM users WHERE email = ?
   → BCrypt.checkpw(inputPassword, dbPassword)
   → Nếu đúng: session.setAttribute("user", userObject)
   → Redirect theo role: admin → admin-dashboard, user → home
```

#### **Đăng xuất (Logout)**
**URL:** `/logout`  
**Servlet:** `LogoutServlet`

**Flow:**
```
GET /logout → session.invalidate() → Redirect home
```

### **3. SHOPPING CART**

#### **Xem giỏ hàng**
**URL:** `/cart`  
**Method:** GET  
**Servlet:** `CartServlet`

**Flow:**
```
1. CartServlet.doGet()
   → Check user login: session.getAttribute("user")
   → CartItemDAO.getCartItems(userId)
   → SQL: SELECT ci.*, p.* FROM cart_items ci 
           JOIN products p ON ci.product_id = p.id 
           WHERE ci.user_id = ?
   → Tính tổng tiền: sum(price * quantity)
   → Forward tới views/cart.jsp
```

#### **Thêm vào giỏ hàng**
**URL:** `/cart`  
**Method:** POST  
**Parameters:** `action=add`, `productId=123`, `quantity=2`

**Flow chi tiết:**
```
1. Form submit từ product page:
   <form action="cart" method="POST">
       <input type="hidden" name="action" value="add">
       <input type="hidden" name="productId" value="123">
       <input type="number" name="quantity" value="2">
   </form>

2. CartServlet.doPost()
   → String action = request.getParameter("action")
   → if ("add".equals(action))
   → int productId = Integer.parseInt(request.getParameter("productId"))
   → CartItemDAO.addToCart(userId, productId, quantity)

3. CartItemDAO.addToCart():
   → Check existing: SELECT quantity FROM cart_items WHERE user_id=? AND product_id=?
   → If exists: UPDATE cart_items SET quantity = quantity + ? WHERE user_id=? AND product_id=?
   → If not: INSERT INTO cart_items (user_id, product_id, quantity) VALUES (?, ?, ?)

4. Redirect: response.sendRedirect("cart?success=added")
```

#### **Cập nhật số lượng**
**Parameters:** `action=update`, `productId=123`, `quantity=5`

**Flow:**
```
CartServlet.doPost() → action="update"
→ CartItemDAO.updateQuantity(userId, productId, newQuantity)
→ SQL: UPDATE cart_items SET quantity = ? WHERE user_id = ? AND product_id = ?
```

#### **Xóa khỏi giỏ hàng**
**Parameters:** `action=remove`, `productId=123`

**Flow:**
```
CartServlet.doPost() → action="remove"
→ CartItemDAO.removeFromCart(userId, productId)
→ SQL: DELETE FROM cart_items WHERE user_id = ? AND product_id = ?
```

### **4. CHECKOUT & ORDERS**

#### **Trang thanh toán**
**URL:** `/checkout`  
**Method:** GET (hiển thị), POST (xử lý)  
**Servlet:** `CheckoutServlet`

**GET Flow:**
```
1. CheckoutServlet.doGet()
   → Check login: if (user == null) redirect login
   → Lấy cart: CartItemDAO.getCartItems(userId)
   → If cart empty: redirect cart
   → Tính tổng: subtotal + shipping fee (30,000đ)
   → Set attributes: cartItems, subtotal, shippingFee, total
   → Forward tới views/checkout.jsp
```

**POST Flow (Đặt hàng):**
```
1. User điền form checkout:
   - address: "123 Nguyễn Văn Linh, Q7, TP.HCM"
   - phone: "0909123456"  
   - payment: "COD" hoặc "Chuyển khoản"

2. CheckoutServlet.doPost()
   → Validation: address, phone, payment không empty
   → Lấy cart items: CartItemDAO.getCartItems(userId)
   → Tính tổng tiền: calculateTotal(cartItems)
   
3. Tạo Order:
   → Order order = new Order(userId, total, shippingFee, paymentMethod, address, phone)
   → int orderId = OrderDAO.createOrder(order)
   
4. OrderDAO.createOrder():
   → SQL: INSERT INTO orders (user_id, total_amount, shipping_fee, payment_method, 
           shipping_address, phone) VALUES (?, ?, ?, ?, ?, ?)
   → Return generated order ID

5. Tạo Order Items:
   → Convert cart items to order items
   → OrderDAO.addOrderItems(orderId, orderItems)
   → SQL: INSERT INTO order_items (order_id, product_id, quantity, price) VALUES (?, ?, ?, ?)

6. Clear cart:
   → CartItemDAO.clearCart(userId)
   → SQL: DELETE FROM cart_items WHERE user_id = ?

7. Redirect success:
   → response.sendRedirect("order-success?id=" + orderId)
```

#### **Trang đặt hàng thành công**
**URL:** `/order-success?id=15`  
**Servlet:** `OrderSuccessServlet`

**Flow:**
```
1. OrderSuccessServlet.doGet()
   → int orderId = Integer.parseInt(request.getParameter("id"))
   → Order order = OrderDAO.getOrderById(orderId)
   → Check ownership: order.getUserId() == user.getId()
   → Load order items: OrderDAO.getOrderItemsByOrderId(orderId)
   → Forward tới views/order-success.jsp
```

#### **Lịch sử đơn hàng**

**Servlet:** `OrderHistoryServlet`

**GET Flow:**

**POST Flow (Hủy đơn hàng):**
```

   → Check status: chỉ hủy được pending/confirmed

```

## 🔐 **SECURITY FEATURES**

### **1. Authentication & Authorization**

#### **Session Management:**
```java

session.setAttribute("user", userObject);

// Check login ở mọi protected page
User user = (User) session.getAttribute("user");
if (user == null) {
    response.sendRedirect("login");
    return;
}

// Check admin role

    response.sendRedirect("login");
    return;

```

#### **Password Security:**
```java
// Đăng ký: Hash password
String hashedPassword = BCrypt.hashpw(plainPassword, BCrypt.gensalt());

// Đăng nhập: Verify password  
boolean isValid = BCrypt.checkpw(inputPassword, storedHashedPassword);
```

### **2. Input Validation**

#### **Email Validation:**
```java
private boolean isValidEmail(String email) {
    String emailRegex = "^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$";
    return email.matches(emailRegex);
}
```

#### **Phone Validation:**
```java
private boolean isValidPhone(String phone) {
    String phoneRegex = "^[0-9]{10,11}$";
    return phone.matches(phoneRegex);
}
```

#### **SQL Injection Prevention:**
```java
// Sử dụng PreparedStatement
String sql = "SELECT * FROM users WHERE email = ?";
PreparedStatement ps = connection.prepareStatement(sql);
ps.setString(1, email);  // Tự động escape special characters
```

### **3. File Upload Security**

#### **Image Upload Validation:**
```java
// Check file type
String contentType = filePart.getContentType();
if (!contentType.startsWith("image/")) {
    throw new ServletException("Chỉ cho phép upload file ảnh");

// Check file size (max 5MB)
```
